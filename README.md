# AI Automation Workflows

A collection of AI and automation workflows built to explore how AI, APIs, data, and different software tools can be connected to automate real-world tasks.

## About

This repository contains practical automation projects built with tools such as n8n, APIs, AI models, and various third-party services.

The goal is to build workflows that reduce repetitive work, connect different systems, process information, and incorporate AI where it adds value.

## Technologies & Tools

- n8n
- APIs & REST APIs
- AI / LLMs
- JavaScript
- Python
- Git & GitHub
- Webhooks
- Third-party integrations

## What I'm Exploring

- AI-powered automation
- API integrations
- Data processing and transformation
- AI agents and LLM workflows
- Workflow design and optimization
- Connecting different tools and services

## Repository Structure

Each project is organized in its own folder and includes its workflow file and documentation explaining how it works.

This repository is continuously evolving as I build and experiment with new automation ideas.
